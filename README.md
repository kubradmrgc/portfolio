# Kübra Demirgüç – Kişisel Portfolyo

Fırat Üniversitesi Yazılım Mühendisliği öğrencisi **Kübra Demirgüç** için
geliştirilmiş modern kişisel portfolyo uygulaması.

## Özellikler

- Hakkımda, deneyim, projeler, eğitim & topluluk, sertifikalar ve iletişim
- Semantik HTML5 ve erişilebilirlik (a11y) temelleri
- React + TypeScript + Vite + Tailwind CSS
- UI Kit bileşenleri (Button, Input, Card, Alert)
- Açık / koyu tema desteği

## Kurulum ve Çalıştırma

```bash
npm install
npm run dev
```

Tarayıcıda `http://localhost:5173` adresini açın.
